Install guide

Install Wild Battles Remastered

Getting from the download to your first wild battle takes a few minutes. The mod works on platforms that support IPSwitch (.pchtxt) patches, and this guide uses the Eden emulator, where it was built and tested.

You'll need
  • Pokémon: Let's Go, Pikachu! or Pokémon: Let's Go, Eevee! from your own legally owned copy, with the 1.0.2 update installed in the emulator.
  • A platform that supports IPSwitch (.pchtxt) patches, with the game already running normally. The steps below use the Eden emulator.
  • About five minutes. This project includes no game files.

Step by step

  1. Download the mod

    Get the zip for your game from the v{{VERSION}} release: {{ZIP_NAME}} for Let's Go, Pikachu!, or {{ZIP_EEVEE_NAME}} for Let's Go, Eevee! Each one only works on its own game. Don't unzip it yet.

    Pikachu Eevee

  2. Back up your save

    In Eden, right-click your game (Pokémon: Let's Go, Pikachu! or Let's Go, Eevee!) and choose Open Save Data Location. Copy that folder somewhere safe. Always do this before trying a new mod.

  3. Add the mod to the game

    Right-click the game again and choose Import Mod from ZIP, then pick the zip you downloaded.

    Prefer doing it by hand? Choose Open Mod Data Location and unzip the file there. You should end up with Wild Battles Remastered/exefs/wild_battles_remastered.pchtxt inside that folder.

  4. Turn it on

    Right-click the game, open Properties → Add-Ons, and make sure Wild Battles Remastered is ticked. Untick any other wild-battle, EXP or catching mod: this one already does all of that.

  5. Play

    Start the game and walk into a wild Pokémon. Instead of the usual catching screen, you'll drop into a turn-based battle.

Using another platform?

Install it the way your platform installs IPSwitch (.pchtxt) patch mods. The zip holds a single patch, Wild Battles Remastered/exefs/wild_battles_remastered.pchtxt, made for game version 1.0.2. Only Eden has been tested so far.

In a wild battle

You doWhat happens
Knock the wild Pokémon outIt faints. The Pokémon that fought earn EXP (real amounts, level-ups, evolutions); the rest of your team gets none. You return straight to the overworld.
Bring it to 25% HP or less, then press YYou go into the game's own catch scene and throw a ball, under the normal catch rules. A catch gives no EXP. (The HP level is the Quick Catch setting.)
Press Y above that HPThe normal Y menu, as in the base game.
Select RunYou flee, as in the base game.

Trainer battles play as normal, except that only the Pokémon that fought earn EXP.

The mod's settings

Open the game's menu, then Options, and go to the last row, Wild Battles Settings. Press A (or left or right) on it and the mod's own page opens. Change what you like, then press B: the game asks whether to keep the changes, and you're back on the normal Options page. Your choices are kept in your save.

On a real Switch (Atmosphère)

Download the Atmosphère zip for your game (Pikachu, Eevee) and copy its atmosphere folder to the root of your SD card, merging folders. You end up with atmosphere/exefs_patches/Wild Battles Remastered/<build-id>.ips, which Atmosphère applies when the game starts. It's the same patch as the Eden mod in the format Atmosphère loads, but it hasn't been tried on a real Switch yet: please tell us how it goes. Play offline only.

Troubleshooting

Nothing changed in battles

Check that Wild Battles Remastered is ticked under Add-Ons, that it's the zip for your game (Pikachu and Eevee each have their own), and that the game shows version 1.0.2 (the update must be installed). Restart the game after changing mods.

Something odd happens in a battle

Turn off every other mod for the game. This mod is self-contained and shouldn't be combined with other wild-battle or EXP mods.

Before a legendary or special encounter

Snorlax, the legendary birds, Mewtwo and the Power Plant Electrode should play as in the original game, because the mod's battle changes only apply to its own wild battles. Nobody has played one with this beta yet, so save first. See everything that has been tested.

Still stuck?

Open an issue on GitHub and say what you did and what happened.
