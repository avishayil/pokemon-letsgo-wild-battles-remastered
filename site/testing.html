How the testing works

  • We save before and after each test and compare the two saved games, so every EXP number above is what the game actually stored.
  • Testing uses the published zip, and we confirm the mod's changes are loaded in the running game before trusting a result.
  • A script generates the mod file and refuses to produce a patch unless its safety checks pass, and the automated tests run on every update to the code.
